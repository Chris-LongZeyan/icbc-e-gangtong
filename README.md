# 港学账本 v0.5

面向同时管理人民币与港币的赴港学生和初入职场青年。主流程：**分类记账 → 保护学费 / 租金 → 按币种检查付款能力 → 必要时双向换汇 → 月度回顾**。八达通只是香港生活补充。

独立比赛原型，非银行官方产品。真实账户与银行 App 内嵌未接通；账户和流水为合成案例，换汇规划使用有来源和日期的官方公开参考牌价。

## 运行

### 本轮重点：在工行已有能力之上扩展

工行已有收支分析、月度账单、教育与大额资金规划；工银亚洲已有 e账通两地账户管理、货币买卖与智安存。不要把这些基础能力说成银行没有。我们探索的增量是 **短期内逐币种、逐日付款能力 + 用途红线 + 最小换汇联动**，仍需登录后实机对照和用户实验确认优势。详见 [官方证据对比](icbc-comparison.html)。

界面采用工银亚洲官网实测主色 `#C4161C`、相近系统字体、白灰卡片和红色操作。没有取得银行内部设计规范，不是官方 App，也不声称完全复刻。

### 独立运行与嵌入运行

- `index.html`：独立壳，模拟账户与本地保存。
- `host-demo.html`：模拟银行宿主，支持390px容器、授权拒绝／超时、规划保存及换汇复核意图。
- `embedded.html`：同一 UI 和计算引擎，通过宿主适配器读取账户及报价；不读独立模式的 localStorage，不回退模拟账户。
- `runtime-config.js` / `embedded-config.js`：部署配置；`host-adapter.js`：四方法契约与消息校验；`shell.js`：数据及保存适配；`bank-theme.css`：集中视觉主题。
- `/module/host-demo.html`：同一套资源部署到子路径的验证入口。

[接入契约](integration-guide.html)描述银行侧字段映射、BFF和生产差距。该接口是本项目定义，不是工行 SDK。小改动复用的是前端模块；真实会话、授权、数据和交易复核仍需要银行联调。网页宿主用 iframe；原生 App 是否可用 H5 取决于其真实容器。

需要 Node.js 20+，没有第三方依赖。

```sh
node generate.cjs
node --test tests/*.test.cjs
node server.cjs
```

打开 http://127.0.0.1:4173/ 。npm run fixtures、npm test、npm start 与上面等价。官方报价刷新需要网络；服务器只监听本机。

## MVP 主流程

| 问题 | 已实现 | 边界 |
| --- | --- | --- |
| 不同领域花了多少 | 分类汇总、手动记账、更正、分类月预算 | 原币统计，不用今日汇率重写历史消费 |
| 查找和忽略支出 | 日期 / 类别 / 币种 / 账户 / 文字筛选，忽略与恢复 | 忽略只影响统计，真实余额和预测仍保留扣款；关联退款同步忽略 |
| 学费租金已到但未付 | 逐项保护、新增 / 编辑 / 移除计划、双币应急金和固定底线、每日红线 | 页面预警，不冻结银行余额，不发后台通知 |
| 总资产够但付款币种不够 | CNY→HKD、HKD→CNY 最小换汇、额外购买检查、保护另一币种用途 | 一次换汇，固定报价，自然日到账，不依赖预计收入 |
| 汇率不能随机生成 | 中银香港公开电汇 CNY / CNH 买卖参考价、来源时间、刷新和失败提示 | 不是工银亚洲成交价；跨境账户可达性、费用与到账另行确认 |
| 月度复盘 | 原币净消费、最大类别、预算偏差、红线检查 | 当前为规则摘要，未调用 AI |
| 香港生活补充 | 八达通 CSV 预览、分类、充值与消费分离、余额核对 | 未接消费者 API，独立于主账本钱包汇总以免重复计入 |

红线 = max（自定最低余额，未来受保护付款 + 应急金），按币种分别算。付款日结束后释放对应预留，并扣除付款一次。红线上方余额仍需覆盖生活费。分类预算只用于分析，未来生活费总额需用户另行确认，避免重复扣款。

## 五分钟演示

1. 小林 / 双币账本：9月净消费HK$8,308，房租6,000、餐饮1,192、日用616、钱包汇总500。筛选房租并忽略后统计为零，账户余额不变；可恢复。
2. 餐饮月预算设HK$1,000，月报显示超出192；可更正逐笔类别。
3. 小林HKD80,000中保护学费50,000、两笔房租12,000、应急金5,000，红线67,000；再预留生活费8,000后余量5,000。固定底线设85,000会预警。
4. 换汇规划载入用户案例：人民币10,000、港币20,000，购买人民币12,000。按CNH客户买入价1.176990、额外费用0，需要换出HK$2,353.98补足人民币2,000；少扣HK$0.01仅得人民币1,999.99。
5. 加入HK$19,000租金预留后，可换资金只剩HK$1,000，购买方案不可行。不会挪用租金。
6. 小周案例演示人民币换港币；增加到账延迟检查能否赶上付款。八达通另作补充演示。

## 官方牌价与真实数据边界

来源：https://www.bochk.com/whk/rates/exchangeRatesHKD/exchangeRatesHKD-input.action?lang=en

official-rates.json 保存真实公开快照，来源更新时间2026-10-03 18:07:55 +08:00。CNH客户卖出1.162840、买入1.176990；CNY分别1.163290、1.175940，均为每元人民币对应港币。rates.cjs校验字段及更新时间；GET /api/rates只访问固定官方页面，不发送账户和流水。已在浏览器验证刷新成功与失败处理。

人民币换港币使用客户卖出价相乘，港币换人民币使用客户买入价相除。报价已含点差；额外手续费另填，向上取分，到账向下取分。费用和延迟默认0仅是模型假设，不承诺免费或即时到账。香港个人兑换通常参考CNH，转入内地付款账户需独立确认费用、限额和到账。

账户案例快照2026-10-02，报价时间独立展示，属于假设场景而非历史成交回放。旧planner.js及其0.91 / 50bp保留用于v0.2回归测试，当前页面用core.js的官方买卖报价模型。

## 验证

110项测试通过，包括200组现金流变化、120组旧模型穷举和120组双向独立穷举。覆盖红线释放、忽略不改余额、买卖方向、缺口、迟到、缺少报价和解析失败；v0.4新增宿主来源／请求校验、超时、拒绝、快照与报价校验及偏好数据边界。node evidence.cjs可重建docs/evidence.json。测试通过不代表银行验收。

## v0.5：简化界面与后续功能

四个主入口：总览、账本、计划、回顾。首页保留可支出金额、原币余额和下一笔付款；高级筛选、逐日依据和接入说明按需展开。换汇、期限匹配和情景测试放入计划的二级入口，八达通放入账本。

- **期限匹配已实现**：逐币种检查整个计划及动态预留，计算存款期间可占用上限。按日历月计算，月底截到目标月末；到期后加1–14个自然日用户缓冲，可用日仍先支付再返还本金。不计预计收入和利息，受保护的学费租金保持流动。超出规划期直接拒绝评估；可编辑规划结束日，同时必须核实生活费和后续付款。
- **真实条款初筛已实现**：使用[工银亚洲网上定期存款官方页面](https://www.icbcasia.com/hk/sc/personal/latest-promotion/online-time-deposit.html)的e时代／综合客户HKD、CNY起存额50,000及1、2、3、6、12个月期限。页面标注2026-09-29，本项目2026-10-03核查。这是手工维护的条款快照，不是实时产品接口；不展示利率或收益，不确认购买资格。账户层级、时段和到期处理仍需银行确认。
- **月度回顾已实现**：原币净消费、与上月已知记录比较、分类超预算及关联流水ID、未分类和钱包汇总提示。不把缺失月份当零消费，不把独立八达通样本叠加到钱包汇总。
- **维护进度已实现**：计划确认、分类核对和分类预算三个任务；修改相关数据会使确认失效，反复点击不累积奖励。确认是用户声明，不是银行核验；摘要校验码仅用于变更检测，不作安全证明。没有可兑换积分或真实权益。
- **偏好保存已实现**：独立模式主动保存；嵌入模式通过原有savePreferences保存wealth与care，不提交流水正文。
- **尚未实现**：投资产品目录与正式风险适当性匹配、真实权益发放、AI生成月报、银行和八达通真实API。当前月报采用可追溯规则，不把模板文字称为AI。AI只在后续对照试验证明解释增益后考虑。

新增15项测试覆盖月底、期限与付款同日、跨币种缺口、规划覆盖不足、真实起存额、容量边界、确认失效、预算证据与偏好隐私。

## 开发与隐私

beyond.js负责期限、回顾和维护状态；minimal-ui.js / minimal.css负责精简工作流；core.js负责分类、红线、双向计算；core-ui.js负责主流程；engine.js负责账本和逐日预测；rates.cjs获取公开报价；octopus.js为香港补充。

个人截图、卡号、真实流水及参考策划书不在仓库。导入在浏览器处理，主动保存才写入未加密localStorage，只适合模拟 / 脱敏演示。没有银行密码、API密钥或AI数据传输。正式版本仍需认证、加密、审计和撤销授权。

分类记账和月报已有成熟产品；项目应证明组合后的付款决策价值，不宣称二分搜索或分类功能本身是发明。
