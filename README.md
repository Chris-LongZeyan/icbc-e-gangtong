# 工银e港通

面向赴港学生及初入职场青年的双币资金管理原型。以分类账本为基础，把必要付款、资金可用日期、最小换汇与产品期限匹配连接到同一套计算流程。

[在线体验](https://dual-currency-e-manager.onrender.com/) · [项目建议书](REPORT.md) · [Qwen 部署与验证](AI_SETUP.md)

## 主要能力

- **账务与预算**：双币账户、分类、组合筛选、统计排除、退款关联及本地导入。
- **资金规划**：学费、租金和应急预留，逐币种逐日核验，购买试算与最小换汇。
- **智能填写**：Qwen 将文字转为结构化字段，直接填入基础设置、收支记录、购买和新增付款表单；缺失信息追问，用户确认后计算。普通话、粤语、英语使用相同流程，Qwen ASR 提供录音转写适配。
- **资金与产品匹配**：结合资金期限、风险偏好、压力损失及门槛筛选候选；存款使用有日期的公开条款，投资类型为明确标注的演示目录。
- **香港生活账本**：八达通导入后合并展示；区分充值与消费，通过汇总关联避免重复统计，保留账面与调整后口径。
- **持续管理**：筛选联动的分类圆环与条形图、月度比较、分类预算、计划维护、保存、撤销及用户中心。

## 使用与运行

首页分为“我的账本”和“演示账户”。个人入口从空白账本开始，支持手动录入、导入和 Qwen 辅助填写；演示入口提供四组虚拟账户。两类存档使用独立存储空间，“返回首页”可重新选择入口。

需要 Node.js 24，应用无第三方运行时依赖：

```sh
npm run build
npm test
npm start
```

打开 `http://127.0.0.1:4173/`。Render 采用仓库根目录、Node 24、启动命令 `node server.cjs`、健康检查 `/healthz`；`render.yaml` 保存部署配置。

## 界面与账务设计

主导航按用户任务划分为总览、账本、计划、我的。账本内分流水明细与收支分析；计划内包含付款与预留、购买与换汇、闲钱安排。未完成账本设置时，导航明确提示所需步骤。

筛选条件统一作用于流水、类别金额和图表。金额按原币展示，收入、充值与换汇记录可查看，但不纳入净消费。退款冲减对应消费，忽略项保留原始账户影响。

八达通导入不修改银行现金余额。对于已经计入账本的钱包汇总，用户选择关联后，将其中一部分拆成商户用途，未覆盖部分保留。例如 HK$500 汇总补充 HK$148 明细后，余下 HK$352 保持未细分，总消费仍为 HK$500。未处理的潜在重叠明细可查看，待关联后计入分析。

界面参考[工银亚洲手机银行官方介绍](https://www.icbcasia.com/hk/sc/personal/internet-banking/personal-mobile-banking/default.html)的常用功能直达，以及[电子结单操作指引](https://www.icbcasia.com/hk/tc/personal/banking/others/e-statement-and-e-advice/view.html)的账户与日期筛选。消费图表是本项目实现，并非对已登录银行界面的复刻。

## 模型服务

Qwen API 默认关闭。配置服务器密钥并确认免费额度后启用，具体见 [AI_SETUP.md](AI_SETUP.md)。未配置时显示待启用状态，手动功能保持可用。密钥不会发送到浏览器。录音、文字与上一草案用于模型处理，完整账单和卡号不随请求上传。

真实模型语义及语音质量需通过实际 API 验收。`node eval-assistant.cjs` 提供普通话、粤语、英语的在线评测；本地接口测试使用测试桩，与真实语义评测区分。

## 验证

176项自动回归覆盖账务、资金约束、最小兑换、产品匹配、模型契约及服务安全。2,000组五日合成案例以独立逐分枚举核对可行性和最小兑换金额。详细决策域、实验分布与结果见建议书。

## 银行集成

独立模式与嵌入模式复用前端及计算核心。`host-demo.html` 展示宿主授权、账户数据、报价、保存和交易复核意图；`embedded.html` 通过受限消息契约接入宿主。Qwen 智能入口当前用于独立体验，机构集成可对接工银智涌及银行鉴权、审计与模型服务。

## 数据与适用范围

这是独立参赛产品。演示入口使用合成账户及交易；个人入口使用用户录入的数据，尚未连接银行。换汇采用附来源与时间的公开参考价；真实成交由银行重新核价。银行账户直连和八达通企业同步属于拟议机构集成范围。投资压力参数用于算法演示，实际产品服务须完成银行适当性评估。

仓库保持私有。公开网页仅分发白名单资源；历史研究、进度记录、个人资料及凭据不在公开路由中。内部模块和存储键保留兼容性，以支持既有浏览器数据。
