# 工银e港通

面向赴港学生及初入职场青年的双币资金管理原型。以分类账本为基础，把必要付款、资金可用日期、最小换汇与产品期限匹配连接到同一套计算流程。

[在线体验](https://dual-currency-e-manager.onrender.com/) · [项目建议书](REPORT.md) · [Qwen 部署与验证](AI_SETUP.md)

## 主要能力

- **账务与预算**：双币账户、分类、组合筛选、统计排除、退款关联及本地导入。
- **资金规划**：学费、租金和应急预留，逐币种逐日核验，购买试算与最小换汇。
- **智能填写**：Qwen 将文字转为结构化字段，直接填入手动试算、购买和新增付款表单；缺失信息追问，用户确认后计算。普通话、粤语、英语使用相同流程，Qwen ASR 提供录音转写适配。
- **资金与产品匹配**：结合资金期限、风险偏好、压力损失及门槛筛选候选；存款使用有日期的公开条款，投资类型为明确标注的演示目录。
- **香港生活核对**：八达通导入、充值与最终消费区分、期初期末余额核对。
- **持续管理**：月度回顾、计划维护、保存、撤销、备份及用户中心。

## 使用与运行

首页提供简要指南；进入体验后选择四个合成场景或建立手动试算。无需登录，数据保存在当前浏览器。“退出演示”返回指南。

需要 Node.js 24，应用无第三方运行时依赖：

```sh
npm run build
npm test
npm start
```

打开 `http://127.0.0.1:4173/`。Render 采用仓库根目录、Node 24、启动命令 `node server.cjs`、健康检查 `/healthz`；`render.yaml` 保存部署配置。

## 模型服务

Qwen API 默认关闭。配置服务器密钥并确认免费额度后启用，具体见 [AI_SETUP.md](AI_SETUP.md)。未配置时显示待启用状态，手动功能保持可用。密钥不会发送到浏览器。录音、文字与上一草案用于模型处理，完整账单和卡号不随请求上传。

真实模型语义及语音质量需通过实际 API 验收。`node eval-assistant.cjs` 提供普通话、粤语、英语的在线评测；本地接口测试使用测试桩，与真实语义评测区分。

## 验证

160项自动回归覆盖账务、资金约束、最小兑换、产品匹配、模型契约及服务安全。2,000组五日合成案例以独立逐分枚举核对可行性和最小兑换金额。详细决策域、实验分布与结果见建议书。

## 银行集成

独立模式与嵌入模式复用前端及计算核心。`host-demo.html` 展示宿主授权、账户数据、报价、保存和交易复核意图；`embedded.html` 通过受限消息契约接入宿主。Qwen 智能入口当前用于独立体验，机构集成可对接工银智涌及银行鉴权、审计与模型服务。

## 数据与适用范围

这是独立参赛原型，账户及交易为合成案例。换汇采用附来源与时间的公开参考价；真实成交由银行重新核价。银行账户直连和八达通企业同步属于拟议机构集成范围。投资压力参数用于算法演示，实际产品服务须完成银行适当性评估。

仓库保持私有。公开网页仅分发白名单资源；历史研究、进度记录、个人资料及凭据不在公开路由中。内部模块和存储键保留兼容性，以支持既有浏览器数据。
