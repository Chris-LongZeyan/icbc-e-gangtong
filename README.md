# 港学账本

面向赴港读书与初入职场青年的 CNY/HKD 资金规划原型。独立参赛项目，非工银亚洲或八达通官方产品。当前版本 v0.2，使用合成数据，无真实账户连接。

## 运行

需要 Node.js 20 或以上，无第三方运行依赖。

```sh
npm run fixtures
npm test
npm start
```

打开 http://127.0.0.1:4173/ 。服务仅监听本机。无需 API key 或 npm install。

## 演示顺序

1. 小林：80,000 港币预留 50,000 学费、12,000 房租、8,000 生活费和 5,000 应急金后，余量 5,000。
2. 小陈：在情景实验室延迟预计生活费 14 天，10 月 28 日首次出现缺口，最大港币缺口 560。与不依赖预计收入的保守路径区分。
3. 小周：打开换汇规划。默认模型中最小人民币扣款 30,180.91，其中费用 150.91，获得港币 33,000；保留人民币 4,819.09。延迟改成 4 天会因来不及到账而不可行。
4. 小许：初入职场，先付租金押金、再等工资，另有人民币付款。最小人民币扣款 26,522.62；全部换汇反而导致人民币付款缺口。
5. 八达通：填入虚构样例 → 预览 → 确认；充值 500、消费 148 分开。输入期初 100、期末 452 可核对算术。重复导入新增 0 条；同一分钟两笔不同金额洗衣记录都保留。

## 已实现

- 双币整数分账本、CSV 预览确认、按 ID 去重、冲突拒绝、消费更正、历史人民币折算来源。
- 逐日币种现金流；预计收入与已到账分开；应急预留与钱包用途约束。
- 四个合成案例，付款日期、金额、币种与压力情景可调整。
- 固定汇率和费用、单次 CNY→HKD 换汇的最小金额求解。BigInt 精确计算费用进位和换汇舍位；整数分二分搜索；少一分钱的反证；导出计算依据 JSON。
- 八达通格式的本地 CSV 转录、分类建议与人工更正、余额差异、充值候选匹配与覆盖完整性声明。
- 浏览器选择性保存；周报 HTML 导出。

八达通明细目前作为独立核对视图，不与主账本的模拟月度钱包汇总相加。用户截图未嵌入代码或提交至仓库。

## 模型边界

默认快照为 2026-10-02，非今天实时余额。汇率、费率和存款均为示例，不代表银行报价。换汇今天扣人民币，指定自然日后日初获得港币；其他预计收入按当天支出之后到账。未实现银行营业日/截止时间、多次换汇择时、真实冻结余额、信用卡全生命周期或自动执行。

单次换汇解的“最小”指当前输入模型内最小人民币总扣款，不代表外汇价格最优、收益最优或真实世界最优。费用为总扣款的比例费用向上取分，加固定费用；兑换金额向下取港币分。

## 接入路线

工银亚洲账户数据和 App 内嵌是两个独立合作事项；八达通消费者跨商户交易接口尚未取得文档、凭据或接入许可。通过本地输入可以完成原型验证。后续经授权的适配器必须提供账户快照、交易 ID、币种、金额、入账状态、覆盖区间和完整同步标志，不能把半页或过期结果标为全量实时。

## 隐私和开发

不收集银行密码。导入在浏览器内处理，无数据上传服务。localStorage 未加密，仅适合模拟或脱敏数据；仅点击保存才写入。重置会删除保存副本。`private/`、`.env`、临时文件和截图不入版本库；该原型不具备生产身份认证、加密存储或审计能力。

关键文件：`engine.js` 账本与预测；`planner.js` 换汇求解；`octopus.js` 本地明细；`features.js` 新界面；`fixtures.js` 案例；`tests/` 验证。

研究报告与正式参赛报告另行维护。旧公开研究页仅作历史证据参考，功能状态以本仓库为准。不要将示例测试、个人观察或接口咨询写成银行验收或用户调研结果。
