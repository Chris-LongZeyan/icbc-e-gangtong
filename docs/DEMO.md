## 开始前

打开[在线原型](https://dual-currency-e-manager.onrender.com/experience.html)，无需登录。使用新的浏览器窗口或确认当前为合成案例；在“演示设置”中选择“小林 · 资金已到位”。准备录屏时可先访问一次，避免免费实例休眠影响开场。

账户数据是演示案例；汇率是具有来源和日期的公开参考报价。页面不执行支付或换汇。

## 五分钟主线

| 时间 | 页面与动作 | 向评委说明什么 |
| --- | --- | --- |
| 0:00–0:30 | 我的：展示双币账户、默认遮罩的 DEMO 卡号和数据来源 | 免登录保留完整产品体验，演示资料与真实连接明确区分 |
| 0:30–1:20 | 总览：观察港币余额 80,000 与可安排额 5,000；展开预留依据 | 余额中包含未来学费、租金、生活费和应急金 |
| 1:20–2:00 | 账本：筛选房租，暂时忽略再恢复 | 用户控制分析口径，但不能因此消除账户实际扣款 |

## 可复现案例一：预留后的可安排资金

小林案例：港币余额 80,000；学费 50,000、两笔租金 12,000、应急金 5,000、规划期生活费 8,000；可安排港币 5,000。

先展示总览结果，再展开依据。若改变付款日期或底线，应重新计算，不把原案例结果沿用到新输入。

## 可复现案例二：最小换汇

“演示设置”选择“双币购买 · 人民币缺口”，进入大额购买，填写人民币 12,000 和规划期内的付款日。

- 持有人民币 10,000 与港币 20,000，人民币缺口 2,000。
- 使用 2026-10-03 的 CNH 客户买入参考价 1.176990、额外费用 0、到账延迟 0，估算需换出港币 2,353.98。
- 将港币 19,000 房租加入受保护计划后，再检查购买，剩余可换资金不足。

若点击刷新后报价变化，最小兑换额也会变化；视频应同时展示所用报价及时间。该案例没有证明跨境转账一定即时或免费。

## 可复现案例三：一分钟手动试算

从“用自己的数字试算”进入，填写以下信息：

| 输入 | 示例 |
| --- | --- |
| 称呼 | 我的试算 |
| 余额日 / 结束日 | 2026-10-03 / 2026-12-02，或其他覆盖付款日的有效区间 |
| 港币 / 人民币余额 | 20,000 / 10,000 |
| 港币应急金 / 全期生活费 | 1,000 / 3,000 |
| 人民币应急金 / 全期生活费 | 0 / 0，仅作为此案例假设 |
| 房租 | HKD 6,000，2026-11-01 |
| 学费 | 0，仅作为此案例假设 |

预期结果：可安排港币 10,000。进入账本新增港币 20 午餐后，港币账户余额降至 19,980；返回总览检查计划同步变化。

余额日是期初资金基数。已经包含在余额里的历史消费，不应再次作为之后发生的流水导入。未填写的支出不在预测中。

## 保存与恢复

“保存”将当前空间存入该浏览器；刷新后可恢复。演示设置允许在案例和手动试算之间切换，其他案例只在当前会话中保留。长期保留可下载备份；恢复前会展示预览。

## 可选补充：香港生活与宿主集成

八达通功能位于账本下的“八达通核对”。说明充值与消费分离、独立样本的覆盖范围和余额核对，不声称已经可以直接读取八达通服务。

[宿主模拟器](https://dual-currency-e-manager.onrender.com/host-demo.html)支持桌面 / 390px 容器、授权成功、拒绝和超时。它展示组件与银行数据层之间的契约；不是银行官方 App 截图。
