# 对外展示与交互体验

报告提供两个公开网页入口，开发仓库保持私有。

- [产品导览](https://dual-currency-e-manager.onrender.com/)：介绍账本、预留及付款试算，使用简洁合成示例说明用途。
- [交互体验](https://dual-currency-e-manager.onrender.com/experience.html)：免登录，选择场景后即可调整输入、检查结果。

## 预设场景

1. 学费与租金：港币80,000元，检查付款和预算后可安排的5,000元。
2. 双币购买：人民币10,000元、港币20,000元，试算人民币12,000元购买。
3. 到账冲突：购买日为10月3日、资金两天后可用；将购买日改为10月5日比较结果。
4. 初入职场：押金、房租与月底工资的时间安排，预计收入单独展示。

## 操作与保存

场景按钮载入初始合成数据；“重置本场景”恢复当前案例。重新打开体验页同样从预设案例开始。“保存”写入当前浏览器，“恢复本机保存”由用户主动载入已保存资料。手动试算、用户中心、分类账本、预算、八达通核对、回顾和扩展工具均保留。

同一站点共用原有计算核心。传统根路径的功能锚点自动转入体验页。报价继续标明来源和时间，真实账户连接、八达通同步与交易执行须由银行接入。
