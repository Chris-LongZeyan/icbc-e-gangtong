# 实验复现：报告技术证据

运行 `node experiments/report-benchmark.cjs`。使用 Node 24，无额外依赖、不联网、不读取个人数据。脚本重建 `results.json`；耗时随机器变化，固定种子的输入与判定应稳定。

## 设计

- 固定种子20261008；2,000组五日、双币、整数分案例。
- 独立 oracle 自行构造每日现金流、费用及到账金额，逐分枚举；不调用生产引擎的预测/报价/红线函数。
- 比较接受/拒绝与最小扣款；任意不一致使进程退出码为1。
- 三个对照是刻意删除条件的模型：总资产、当前原币＋兑换、保留未来义务但去掉到账约束。它们不是银行产品。
- 总资产模型使用买卖方向换算，但不扣费用、不预留未来付款；第二模型计费用但不计未来用途/生活费/底线和延迟；第三模型只取消延迟。

421组需换汇，682组无需换汇，897组不可行；与独立枚举不一致0组。三种删减模型错误放行分别814、809、295组；完整模型0组。该样本是边界导向的合成分布，不是现实误判概率。

136项既有回归测试另外通过。最初受沙箱localhost网络限制的HTTP测试，在允许本地连接的环境重跑全部通过，未通过删测试解决。
