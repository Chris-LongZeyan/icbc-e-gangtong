港学账本 · ICBC 增量能力核查 · 2026-10-03

基于已有银行能力，补上双币付款规划

定位建议：为赴港学生与初入职场青年提供按币种、日期和用途约束的短期资金规划模块，嵌入工行已有账户与跨境服务。八达通作为香港小额消费明细补充。

独立原型 · App / 官网宿主演示 · 接入契约与边界

结论与证据边界

基础记账、跨境账户查看、换汇、目标规划、AI 和权益激励均不能笼统宣称是工行没有的功能。本次通过工行内地、工银亚洲官方产品页、个人信息保护政策、2026 年系统公告及年度报告核查；两地产品分别比较。公开网页不能穷尽登录后所有功能、客户分层版本及在研功能。

我们的差异是一个待验证的组合：同一规划同时约束两种币种、逐日付款、已到资金的指定用途和换汇到账。未找到完全相同的公开功能说明，不等于证明工行没有。报告宜使用“在既有能力上增加面向赴港青年的短期双币支付可行性检查”，不使用“行业首创”“工行首个”。

功能逐项对比

能力工行已有证据我们的增量及不能声称的内容判断
流水、收支和月报内地工行灵通账户卡页面说明账户明细和月度账单分析；2026 年系统公告明确列出收支分析、客户收支明细与工小智相关场景。[1][2]分类、筛选、排除交易是基础体验。我们的统计排除不改变现金预测，且原币消费不被今日汇率改写。具体工行现版分类编辑／忽略选项还需登录实机核验。基础重叠，不作主要创新
两地账户统一查看工银亚洲 e账通可添加内地同名账户、查询明细及办理注册账户转账；隐私政策明确境内余额、交易明细等数据用途。[3][4]应复用 e账通已有授权和账户展示，再加入未来付款安排。不可宣传首次打通两地账户，也不能继承用户已有授权而省略新的用途确认。已有底座，规划层扩展
教育金、大额资金规划内地智能资产规划覆盖养老、子女教育和大额资金；结合目标、期限、风险和现金流形成配置方案。[5]我们聚焦当前学期／入职期内已确定付款：不同币种是否在指定日期可用、学费提前到账后的可花余额、临时购买是否影响租金。不是“银行只有回顾、我们才有前瞻”。最重要的重叠项；差异需场景实测
资金保护工银亚洲智安存可真实锁定存款，限制支出，必须亲临分行核实后解锁，用于防诈骗。[6]我们的红线是可随付款日释放的规划预留和软预警，不冻结资金，不替代智安存。真实被冻结资金必须由宿主标成不可用于支付。目的与机制不同，可互补
换汇、跨境支付工银亚洲已有货币买卖、电汇、跨境支付通等功能；e账通优惠亦显示最终交易复核报价。[7][8]增加“为这笔付款需要换多少、何时到账、会否动用另一币种租金”的前置检查。再交回银行交易复核，不重建交易系统。当前 BOCHK 报价是外部参考，接入后换成银行适用报价。交易前的决策支持增量
风险匹配、AI 与激励工行已有风险承受能力匹配及产品配置；2025 年报披露智享+1.0、智能交互与工银 i豆权益。[5][9]先做付款约束下的可用金额／最迟可用日，再复用银行适当性和产品服务。AI 若加入，只解释可追溯计算；积分鼓励预算核对。AI／积分本身不算创新。下一阶段复用，避免重复造功能
开放接口工银亚洲官网列出个人账户授权查询、货币汇率、产品信息 API 与沙盒申请能力；网页同时称暂无第三方服务供应商合作伙伴。[10]证明合作渠道存在，不代表项目已有权限、交易明细字段齐全或零成本。内部自有模块与外部第三方合作的接入条件不同。可申请，尚未真实连通

可作为比赛主张的三项增量

  1. 逐币种、逐日的付款可行性。总资产估值充足，仍可能在人民币付款日缺人民币，或换汇后港币租金不足。模型显式检查两条现金流。
  2. 用途预留与最小换汇联动。已到账学费、租金、应急金与日常生活预算共同约束可换金额，并显示方案不可行的原因。
  3. 可审计的资金口径。统计排除不改余额，钱包充值不重复算消费，历史消费不随今日汇率重估；计算保留报价来源、费用假设及少一分钱不足的验证。

这些是场景与工程实现的增量，不是声称新的数学算法。竞争力最终取决于相对现有流程，用户能否更快、更准确完成资金安排。

公平验证方案（尚无用户实验结果）

用同一组模拟资产与付款任务，对比“银行现有账户／规划／换汇流程”与“加入此模块”。不要虚构对照结果或给银行错误功能设定。

任务验证问题指标
CNY10,000 + HKD20,000，购买 CNY12,000能否发现人民币缺口并计算换汇？正确率、耗时、来回切换次数
上述港币中19,000需交租是否错误认为可支付？错误放行次数、解释准确性
学费提前到账但四周后才交能否得到付款前合理可花金额？与验证模型差异、红线理解率
换汇到账晚于付款日／生活费未到能否识别时点风险？漏报、误报、修改计划完成率

先完成真实 App walkthrough；再招募少量目标用户探索问题，记录样本规模，不把小样本当总体结论。若现版已具备同等组合，应进一步收窄到赴港青年具体任务。

UI 与嵌入设计

实测工银亚洲官网链接／导航主色为 RGB(196,22,28)，即 #C4161C。网页字体栈为 HelveticaNeue、Arial、Microsoft JhengHei、Microsoft YaHei、PingFangTC 等。结合官方手机银行操作图中的白底、红色操作、浅灰分组和清晰列表，原型已改为同类风格。

这是公开资料驱动的视觉适配，未取得工行内部设计系统，不声称逐像素复刻当前 App。采用系统中文字体，不捏造专有字体；主题集中在 CSS。保留独立参赛原型标识。

保留独立 Node 外壳，通过 embedded.html 加载同一 UI 和计算引擎。部署配置、宿主适配器、银行后端字段映射是预定替换点。实际银行登录态、授权、接口及安全联调不能承诺“改几行就上线”。
